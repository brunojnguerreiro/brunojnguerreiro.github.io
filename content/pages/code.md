Software, datasets and templates that I make available, mostly related to drone
control, estimation and simulation. All my public repositories are on GitHub:
[github.com/brunojnguerreiro](https://github.com/brunojnguerreiro).

## nova-drone-arena

<img src="{static}/images/code/nova-drone-arena.jpg" alt="Illustration of the NOVA DroneArena netted flight cage with three drones" style="width:100%;max-width:480px;height:auto">

Software for the NOVA-DroneArena, the drone testbed at NOVA School of Science
and Technology, developed by Hugo Cabrita in his MSc thesis. Includes an
installation guide, MATLAB/Simulink controllers, the Marvelmind indoor
positioning configuration and C++ code for testing the drone. *C++, MATLAB*

[Repository](https://github.com/brunojnguerreiro/nova-drone-arena)

## replace-dataset1

<img src="{static}/images/code/replace-dataset1.png" alt="Sample plots: RGB image, depth point cloud, and inertial trajectory with features" style="width:100%;max-width:480px;height:auto">

Dataset from the [REPLACE](http://replace.isr.tecnico.ulisboa.pt/) project for
validating simultaneous localization, mapping and moving object tracking
(SLAMMOT) algorithms. Motion-capture ground truth and RGB-D camera data in a
ROS bag, with MATLAB code to parse and plot it. *MATLAB*

[Repository](https://github.com/brunojnguerreiro/replace-dataset1)

## nova-ieec-m262

<img src="{static}/images/code/nova-ieec-m262.png" alt="Simulated drone height responses for different controller gains" style="width:100%;max-width:480px;height:auto">

Class repository for module 2.6.2 (Systems, Decision and Control) at NOVA FCT:
a simple drone simulation for tuning the gains of a height controller and
comparing the responses. *MATLAB/Octave*

[Repository](https://github.com/brunojnguerreiro/nova-ieec-m262)
